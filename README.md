## 国外虚拟主机推荐里最容易被搞混的：共享主机和 VPS

搜“国外虚拟主机推荐”的人，实际要的经常是两样东西，买错方向的成本比买贵更高。

共享主机对应的是这些需求：装 WordPress、后台是 cPanel 这种图形界面、点几下就能建站、不碰 SSH、站点是博客/官网/作品集这类常规应用。服务器环境、备份、安全补丁由主机商负责，出问题开工单。

VPS 对应另一类需求：要 root 权限、要跑常驻进程、要装 Docker、要自建 AI 应用或代理节点。RackNerd 自己也有 KVM VPS 促销线，但那是无管理服务，装系统、排故障都得自己来。

判断标准很直接：你能说清楚“我要在服务器上装什么、跑什么进程”，才需要 VPS；说不清楚，只是想有个网站，共享主机就够了。本文主线是后者，VPS 放在后面单独一节。
